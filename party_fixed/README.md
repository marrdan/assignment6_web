# Assignment 6 - jQuery: The Party

- `task1/` - Selector Detective: the party is built from an array (`data.js`), 20 cases with one jQuery chain each.

Open `task1/index.html` or `task2/index.html` in a browser (internet is needed for jQuery and the avatars).
Libraries: only jQuery 3.7.1. No onclick attributes, no CSS transitions or animations.
